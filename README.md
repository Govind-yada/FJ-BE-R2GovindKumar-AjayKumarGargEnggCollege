# FJ-BE-R2 [Your-Name]-[Your-College]

A comprehensive **Personal Finance Tracker** web application built as part of a backend engineering assignment.

## Overview
FinFlow lets users track income, expenses, and investments with real-time insights, 
budget monitoring, and AI-powered financial analysis.

## Features
- 🔐 JWT Authentication + Google OAuth
- 💸 Transaction Management (income, expense, investment)
- 💱 Multi-currency support with live FX conversion
- 📊 Dashboard with charts and financial overview
- 🎯 Budget goals with email alerts (warning + overrun)
- 📈 Reports — monthly, category breakdown, net worth
- 🤖 AI Chat, financial insights via OpenAI
- 🧾 Bank statement import (PDF/CSV) with auto-categorisation
- 🚨 Anomaly detection for unusual spending patterns
- 📎 Receipt uploads per transaction
- 📧 Email notifications via SendGrid

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Auth:** JWT, Passport.js, Google OAuth 2.0
- **AI:** OpenAI API
- **Email:** SendGrid
- **Frontend:** Vanilla HTML/CSS/JS
